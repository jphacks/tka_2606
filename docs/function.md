# ステップ3：機能の優先順位づけ（MVPの策定）

## コア機能（v1.0に入れる）

### S tier（絶対に入れる）

| 機能 | 内容 |
| --- | --- |
| **とりあえずこれやれ機能** | アプリを開いたら今日のメニューが1つだけ表示され、すぐスタートできる |
| **運動ランク診断（アンケート）** | 簡単なアンケートで、自分が取り組むべき運動ランクがわかる |
| **今日の運動レポート** | どのくらいの時間運動したか、消費カロリーなどを表示 |
| **ストリーク機能** | Duolingoのような継続日数カウント |

### A tier（できれば入れる）

| 機能 | 内容 |
| --- | --- |
| **運動の効果表示** | その運動がどんな効果を持つかを表示（簡単版と詳細版）。カロリー、鍛えられる部位、有酸素運動の効果、睡眠の質、日常生活でのメリット |
| **並べ替え機能** | かかる時間、難易度、消費カロリーごとにメニューを並べ替えられる |
| **メニュー提案機能** | 複雑にしない。やることは明確に、選択肢は少なく |

---

## 画面構成（v1.0）

| 画面 | 主な要素 |
| --- | --- |
| **ログイン画面**（追加） | サインイン／サインアップ（1タップで完了させる） |
| **オンボーディング画面** | 「今のあなたの運動レベルは？」3択（全く運動していない／たまに歩く程度／少しは体力に自信あり）→ 体力に合ったメニューをおすすめ |
| **ホーム画面** | ストリーク表示（例：3日連続）、レベル、「今日のメニュー：3分間サーキット」（難易度・消費カロリー）、**時間の＋／－ボタン**（追加）、スタートボタン、今日の完了人数 |
| **運動中画面** | 何個目か（例：2/3個目）、種目名、残り時間のタイマー、次の種目、一時停止ボタン |
| **レポート画面** | 「クリア！お疲れ様」、ストリーク更新（例：3日→4日連続達成）、運動時間、消費カロリー、レベルアップまでのXP、他ユーザーの完了通知、ホームに戻るボタン |

---

## このアプリでできること（全機能一覧）

### メニュー・運動
- メニューを提案してくれる機能（複雑にしたくない。やることは明確に。選択肢は少なく）
- かかる時間、難易度、消費カロリーごとに並べ替えられる
- とりあえずこれやれ機能
- その運動がどんな効果を持つかを表示（簡単なのと細かいの。カロリー、部位、有酸素運動にはどういう効果があるのか、睡眠の質、日常生活でのメリット）
- メニュー表

### 継続・モチベーション
- ストリーク機能（Duolingoの継続カウントのようなもの）
- レベル上げ機能（レベルの上がり方は一定であってほしい）
- 罰金機能（自分に罰を与えたい人だけ）

### 記録・レポート
- 今日行った運動レポート（どのくらいの時間運動したか、消費カロリー）
- 毎週・毎月の運動レポート

### ユーザー・つながり
- サインイン・サインアップ
- 運動ランク診断（アンケートで自分の運動すべきランクがわかる）
- 近くにいる自分と同じレベルの運動したい人とのマッチング機能（マップやタグを使って）
- スタディプラスのような機能（他の人の記録が見られるタイムライン）
