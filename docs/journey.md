# ステップ2：ユーザージャーニーマップ（20歳大学生編）

昼夜逆転で「このままじゃヤバい」と焦りつつも、ハードな運動は続かないし、調べるのも面倒。
そんな彼が「これなら毎日やっちゃうな」と感じるまでの体験（感情と行動の流れ）を時系列で設計する。

---

## 1. アプリとの出会い（認知〜インストール）

- **状況**：お昼の12時に起床。ベッドの中でスマホをいじりながら「また昼に起きちゃった…体力も落ちてるし何か始めなきゃ」と少し自己嫌悪。
- **行動**：手軽そうな運動アプリを見つけてインストール。
- **感情**：「また面倒な登録とか、長いアンケートがあったら即消そう」と警戒している。

## 2. オンボーディング（初期設定は「秒」で）

- **行動**：アプリを開く。サインインは1タップ。アンケートは「現在の体力レベルは？（3択）」など最小限のみで、即座にランクが決定。
- **感情**：「お、設定これだけ？すぐ終わった！」と少しテンションが上がる。
- **機能のヒント**：ここで細かいプロフィール入力や複雑な設定はさせず、離脱を防ぐ。

## 3. 初めての運動（前置きゼロで即スタート）

- **行動**：ホーム画面に遷移すると、いきなり「今日のメニュー：3分間サーキット」がデカデカと表示されており、「スタート」ボタンしかない。
- **感情**：「YouTubeみたいに選ぶ手間がない。3分なら今ベッドから起きてパッとやれるな」と、考える前に体が動く。
- **機能のヒント**：選択肢を極限まで削る。まさに「とりあえずこれやれ」機能の真骨頂。

## 4. 達成感と繋がり（運動直後）

- **行動**：運動完了。画面に「消費カロリー」と「体力回復まであと少し！」といったポジティブなフィードバックが表示される。
- **行動**：同時に、「たった今、同じレベルのユーザー3人が運動をクリアしました！」という通知や、他のユーザーのゆるい記録（タイムラインやタグ）が目に入る。
- **感情**：「自分以外にも今起きて運動してる人がいるのか。なんかいいな」と孤独感が薄れる。

## 5. 習慣化（2日目〜1週間後）

- **行動**：翌日の午後、アプリから通知。開くと「ストリーク：1日」の炎アイコンが燃えている。
- **感情**：「せっかく昨日やったし、今日も3分だけだしやるか」と継続。他の人の記録を見て「あいつも続けてるな」と勝手に仲間意識や小さな競争心を持つ。

## 6. 4日目（マンネリ打破）

- **行動**：コミュニティ機能を使う。
- **感情**：3日やったら飽きてきた。コミュニティ機能があるから、そこに入って刺激を受けたい。

---

## まとめ：この体験から見える最重要ポイント

| 最重要ポイント | 対応するフェーズ |
| --- | --- |
| **前置きゼロですぐ始められること** | 2. オンボーディング／3. 初めての運動 |
| **他の人の存在をゆるく感じられること** | 4. 達成感と繋がり／5. 習慣化／6. 4日目 |
